# Home Assistant Add-on: FilaMan

Filament management for 3D printing, running next to Home Assistant.

Track every spool with its remaining weight, material, colour and location, see
which spool sits in which AMS slot, scan RFID tags to find a spool instantly,
and let printer plugins (Bambu Lab, Bambuddy, Moonraker, Spoolman) report
consumption automatically.

Pairs with the [FilaMan ESP32 scale][esp32]: put a spool on the scale, the
remaining weight lands in FilaMan.

After starting the add-on, open the web interface with **OPEN WEB UI** and log
in with the e-mail and password you configured.

See [DOCS.md](DOCS.md) for configuration, first login and troubleshooting.

[esp32]: https://github.com/Fire-Devils/FilaMan-System-ESP32
